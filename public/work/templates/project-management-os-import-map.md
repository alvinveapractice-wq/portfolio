# Import Map
| Order | File | Resulting database | Main purpose |
|---|---|---|---|
| 1 | 01_Projects.csv | Projects | Portfolio-level project records |
| 2 | 02_Tasks_and_Milestones.csv | Tasks and Milestones | Work items, deadlines, milestones |
| 3 | 03_Team_Workload.csv | Team Workload | Capacity and hours planning |
| 4 | 04_Risks_and_Issues.csv | Risks and Issues | Risk and issue tracking |
| 5 | 05_Decisions_Log.csv | Decisions Log | Decision history and follow-ups |
| 6 | 06_Meetings_and_Updates.csv | Meetings and Updates | Reporting, notes, action items |
| 7 | 07_Project_Templates.csv | Project Templates | Reusable kickoff, review, closeout prompts |

IDs in the CSV files are matching keys, not live Notion relations. Use the setup guide to add relations and manually connect records.
